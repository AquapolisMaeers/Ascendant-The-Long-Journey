# Local fonts

The game hosts these fonts locally, with no runtime requests to Google Fonts:

- **Barlow Condensed**, Bold and Bold Italic: display headings and navigation. [Google Fonts specimen](https://fonts.google.com/specimen/Barlow+Condensed), [upstream files](https://github.com/google/fonts/tree/main/ofl/barlowcondensed). License: `barlowcondensed-OFL.txt`.
- **Source Sans 3**, variable regular: body copy, controls and numerical information. [Google Fonts specimen](https://fonts.google.com/specimen/Source+Sans+3), [upstream files](https://github.com/google/fonts/tree/main/ofl/sourcesans3). License: `sourcesans3-OFL.txt`.

Both are distributed under the SIL Open Font License 1.1. Original font files and license notices are included unchanged. Georgia remains available for selected narrative details.
